AOS.MINIMAL — The Event
A was standing.
The ceiling was not.
NAME CeilingCollapse.A.2026
FACT Structural element failed. Human beneath. Contact occurred.
TARGET Survive. Treat. Account.

One second: a room. Next second: rubble.
A did not move. The ceiling moved for them.
AOS.MINIMAL sees only what happened — no blame, no drama, no metaphor.
A NAME. A FACT. A TARGET. The rest is consequence.

AOS.BUG-MIB — The Bug

that waited.

FIX REQUIRED Full structural audit. Owner liability established.
OWNER B

Bugs do not announce themselves. They accumulate.

AOS.BUG-MIB names what the building forgot to say.

AOS.ENGINEERING — The Structure
Requirement existed.
Compliance did not.
NAME Ceiling.Unit7.StructuralAudit
REQUIREMENT NEN 6702 §4.2 — Inspection cycle: 5 years. Load tolerance: 180 kg/m².
FAILURE MODE Propagating fatigue crack. Initiating point: anchor bolt corrosion.
ROOT CAUSE Zero inspections in 11 years. Humidity ingress unreported.
VALIDATED CAUSE Negligence. Preventable. Owner-attributable.

Engineering does not speculate. It validates.
The requirement was written. The schedule was set. The inspection never happened.
AOS.ENGINEERING moves from Requirement to Validated System —
and here, the system failed validation by 11 years.
